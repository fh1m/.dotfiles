# Notes are working material

Write anywhere. Templates are prompts, not forms you must fill. A folder is storage; links explain the relationship. You may split a vault when it serves a real boundary, not because a subject has a name.

## Native tools
- **Properties + Bases:** optional roles, source state, resume points and review dates. Edit a property once; its views reflect it.
- **Backlinks / local graph:** inspect what supports an idea and where it is used. A graph is a map, not a mastery score.
- **Canvas:** arrange notes, PDFs, images and models spatially. Important ideas belong in linked Markdown notes too; free text cards alone do not give the same backlink trail.
- **Equations:** `$x$` inline, `$$...$$` for display. State assumptions, symbol meanings and units or representation.
- **Diagrams:** fenced `mermaid` diagrams, Canvas and Excalidraw. Use the existing freehand plugin only when you need drawing.
- **Attachments:** images, PDF pages, audio and video can be embedded with `![[file]]`; large raw runs stay outside vault Git.
- **Daily notes:** a lightweight log with links to real work, not a second copy of it.
- **Bookmarks / search:** saved entry points and native search; no mandatory dashboard ritual.

## Resources and evidence
Reading a chapter, solving a problem, and transferring a model are different accomplishments. Record the actual activity. Keep author claims, your model and observations separate. Preserve attempts before hints and later retry independently.

## Research tools
Zotero holds references and original PDF annotations. Sioyek is the focused technical reader. Zotero annotations live in its database; export an annotated PDF if you want them visible outside Zotero. Import Markdown annotation exports with `noesis import-notes`, keeping imported excerpts separate from your own synthesis. Repeated imports update only the generated excerpt.

## Lifelong portability
Markdown, Canvas JSON and Bases YAML are inspectable. You can move notes and change folders. Tracked records receive stable IDs; new work is not tied to the current laptop or a particular subject. Local backups are automatic; off-device backup is a separate choice.
