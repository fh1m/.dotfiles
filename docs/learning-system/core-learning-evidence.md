# Core learning: visual thinking and explicit execution

This slice extends the existing self-service learning thread. It introduces no
new record type, graph authority, execution daemon or notebook platform. Artifacts,
experiments, questions, relationships and activities retain their existing IDs and
owning vaults. All acceptance content is labelled **agent validation**, never an
owner achievement.

## User workflow

1. Today → Start learning → paste a source or enter a question → Continue → Save.
   A separately supplied title does not discard the question or problem statement.
2. Working page → Draw / Diagram → title → Canvas or active Excalidraw → Create
   linked drawing. Obsidian edits the owned file. Back recovers the originating
   record. More → Rename / locate linked file reconnects the same artifact ID.
3. Working page → Try in code → optional prediction → blank starter or existing
   Python file → Create scratch experiment. The editor opens the actual code.
4. Return → Open terminal to run → inspect command → Enter deliberately. Each run
   captures code bytes, hash, optional Git revision, Python/package versions,
   command, timestamps, stdout, stderr, exit status and generated PNG/CSV/JSON.
5. Return → Lab shows actual captured output and original prediction. Record an
   interpretation separately; exit code zero never awards understanding. Failed
   runs remain alongside subsequent corrected runs. Inspect run files exposes the
   full capture. Back returns through the original question/source.
6. Research annotation → Ask about this annotation retains paper, attachment,
   annotation, projection hash, revision and exact owner without copying source
   annotation text into learner interpretation. Open this annotation validates
   current native identity; historical/deleted annotations use a labelled fallback.

## Verification scope

`check-noesis-exploration.py` begins with an empty isolated vault. Native buttons,
fields and selectors create every Noesis record. Native Obsidian opens owned Canvas,
Excalidraw and derivation files; Neovim edits code; a visible terminal requires Enter
before execution. External fixtures provision an isolated genuine PDF and annotation,
not prearranged Noesis records. The Zotero test-only URI transport targets an isolated
copy of the installed app and calls its unchanged native protocol handler. It reads
actual selected annotation and physical page state; it does not certify every vendor
version or external reader. Personal Zotero data and plugins are untouched.

The Python suites pass **157 core tests**, plus **16 compatibility tests**. Ten native
shutdown checks cover debounce, active mutation/import, failed save, forced termination,
uncertain receipts and retained context. Scoped installation is idempotent, reversible
and protects later edits and unrelated files. No new performance or educational
outcome is inferred from those checks; previous measured query/frame limits remain
in validation.md.

## Remaining limits

- Drawings are edited in Obsidian. Native previews require an adjacent PNG export;
  potentially stale exports are labelled. No interactive drawing engine was added.
- Excalidraw must already be enabled and active in the owning vault. Canvas remains
  available without community plugins; no personal plugin is installed.
- Capture is an explicitly invoked local Python check with a 120-second timeout,
  not a sandbox or managed long-running job service. Interrupted capture remains
  visible; uncertain execution is never blindly replayed.
- Existing Python files and repositories are accepted; automatic evidence proves
  executed bytes, not unaided authorship or conceptual understanding. Assistance
  remains an explicit learner declaration.
- Main Hide stops indexing. ScreenPad can hold cached context during tool handoff,
  with a visible paused-update label and read-only notes until Noesis returns.
- Zotero populated restore is fixed only for the guarded inspected 10.0.6 build;
  retain its rollback and revalidate upgrades. Broader P0–P8 fault, storage-conflict,
  long-history, portability and sustained-owner-use gates remain open.
- Off-device configuration remains owner-deferred. The owner's real learner trial
  is required before declaring V1 complete.

Native screenshots and actual run manifests: [core-learning assets](assets/core-learning/).
The canonical guide is [bundled user guide](../../home/.local/share/sensei-learning/ui/user-guide.md).

Native integration uses the supported Obsidian [CLI move contract](https://obsidian.md/help/cli); Noesis additionally checks filesystem postconditions because a successful native move can lose its acknowledgement. That confirmation preserves identity without repeating the mutation.
