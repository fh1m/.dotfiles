# Learning with Noesis

Noesis connects sources, questions, reasoning, practice, code and evidence. Your Markdown records remain the authority. Reading, using, understanding and independently demonstrating an ability are separate facts.

## Begin and return

Choose an authorized learning vault using the vault selector in the left navigation. Noesis does not automatically adopt discovered directories. If none is available, vault setup remains necessary before saving. Do not choose Downloads as your learning vault.

Choose **Start learning** in the toolbar, or press **Ctrl+N**. Paste a URL or enter a question; choose a local file or select **Choose from Zotero**. Select the format and enter a recognizable title. **Continue** opens the ordinary record form; **Save** opens its working page. The title and outline are yours: Noesis does not extract transcripts or invent metadata. [Start now](noesis:start).

**Today** offers resume context and explained suggestions. **Back to Learn/Research/Practice/Lab** returns to a collection. **Previous activity**, or **Alt+Left**, returns to earlier work. Close and reopen Noesis to restore saved navigation and drafts. Hide retains context and stops background indexing. Close waits for pending writes or exposes unresolved receipts.

## Sources and reading

- **Video or lecture:** paste the video URL; save a timestamp under **Set a reading place**. Open the original source in the browser. Automatic transcript import is unsupported.
- **Playlist / Course / Book:** create the source, then use **Course options → Add lesson or chapter**. Name each unit and optionally add its original URL/file. Units own their reading places and history. Outline editing exposes move controls. No automatic playlist expansion is promised.
- **Article / Documentation:** choose the format, save its URL, then use **Open original source**. Capture your explanation alongside the bounded native preview. Noesis is not a browser.
- **Paper / PDF:** choose a local file or use Zotero search. A manually entered paper is not automatically a Zotero bibliography. Zotero imports preserve source identity and annotations; repeat imports must retain authored analysis.

Use **Set a reading place**, enter a page, section or timestamp, and **Save reading place**. Saved places are context, not proof that a lesson was understood. Use **Ask a source-linked question** to preserve uncertainty. **Save study note** preserves your explanation in activity history.

## Rich thinking in Obsidian

**Edit complete note in Obsidian** opens the owned Markdown note. Investigation pages offer **Open derivation in Obsidian**. Use Obsidian for equations, diagrams, backlinks, Canvas and rich derivations. Noesis does not replace these editors or automatically construct a Canvas. Plugin-specific features require their existing supported setup; Noesis does not install plugins into your personal vault.

## Questions, concepts and prerequisites

Start a **Question** or **Concept or topic** from Start learning. Investigation shows your current question, evidence, unresolved mechanisms and connected work. **Connect a deeper mechanism** finds existing material and records why it matters. Choose required, parallel or optional deeper study deliberately. An optional descent does not lock ordinary exploration.

Open the connected mechanism, then use **Previous activity** to return. Create missing concepts through Start learning before connecting them. Noesis derives this frontier from relationships and historical activities; it does not create another score database. Evidence decisions require a criterion and honest supporting evidence. Unknown is not failed; assisted is not independent.

## Practice and reviews

Choose **Practice problem**, write the statement and criterion, and keep solutions separate. Start a protected attempt before consulting references. Statement and reasoning share the working page; narrow layouts provide a focused switch. Save the actual outcome and assistance. Reveal references deliberately: exposure stays in history.

A failed attempt can produce a linked question. **History & next steps** offers retry, changed-problem transfer and scheduled independent checks. Planning a check does not mean it was performed. An accepted submission or working code does not prove unaided reasoning.

## Code, experiments and results

**Connect implementation** links an existing Git repository and optional contained code file. **Open code** uses the configured editor/terminal. Noesis observes commit and dirty state; opening an editor is not execution evidence. Source code is never automatically executed.

From an implementation, **Begin a run** (or **Learning options → Add experiment run**) records your prediction and configuration. **Record comparison** (also available as **Compare prediction and observation** in contextual actions) records reported measurements, units, conditions, uncertainty and interpretation. **Connect artifact** (also **Connect data, figure or code** in contextual actions) references an existing artifact. Checksum inspection proves which bytes were inspected, not the hypothesis. Figures must be supported local image formats; unsupported artifacts retain an explicit handoff.

Generic experiments run in your existing terminal, notebook or simulation tooling. Attach actual outputs and record the code revision and conditions. Convolution has an explicitly invoked bounded demonstration; other subjects do not inherit a generic execution engine. New reconstruction starters are skeletons. Supplied examples and agent-produced outputs are labelled and are not your achievements.

## ScreenPad

The Study desk follows your selected activity. Choose source, context, notes, figures or reference in each pane. Shared notes retain the editing owner. **Keep here** pins supporting context; it must not change the owning record of active edits. Protected references remain protected. **Use ScreenPad for tools** releases the secondary display for specialist applications. Missing displays do not create another learning index.

## Search, ownership and settings

**Ctrl+K** opens search and also offers Start learning from a new source. [Find existing work](noesis:search). Today and Library can show **This vault** or the already authorized learning collection. Opening a cross-vault result selects its actual owner; saves retain that owner. Newly discovered storage is not automatically authorized.

Settings control interface and reading scales, window presentation and workspace preferences. Study fullscreen uses the configured main display with a fallback. Existing external windows are not forcibly moved.

Shortcuts: **Ctrl+1–6** Today/Learn/Research/Practice/Lab/Library; **Ctrl+N** Start learning; **Ctrl+Shift+N** quick capture; **Ctrl+Enter** primary submission; **Alt+Left/Right** navigation; **Ctrl+I** context; **Ctrl+.** contextual actions; **Ctrl+Shift+F** focus. Mouse equivalents remain available. Escape closes the top layer. Reasoning editors retain Tab indentation.

## Problems and safe recovery

Unavailable source: retain the owned record and reading place; reconnect storage or repair the original location. A failed handoff is not a completed learning activity. Do not repeatedly launch a mutation whose receipt is uncertain: inspect its status and owner first.

Failed save: keep the draft, correct the inline error and retry only after receipt status is known. Missing repository or artifact: restore its original path or deliberately reconnect it; do not invent outputs. Identity conflicts require explicit resolution; filenames are not stable identities.

Local backup and restore remain available through the existing recovery workflow. Advanced recovery and vault adoption are not entirely self-service UI workflows. Populated native Zotero restoration now passes the isolated encrypted restore test with a guarded local Zotero 10.0.6 startup compatibility patch. Annotation-specific navigation and the broader recovery matrix remain acceptance gates; a vendor update must be revalidated. Off-device backup configuration is deferred by owner. A graceful Close cannot guarantee recovery from power loss; local durable writes and draft recovery protect what was actually saved.

Native empty-vault acceptance exercises manual source creation, playlist units, questions and prerequisite return, protected Practice, Obsidian/editor handoffs, executed code and Lab artifacts, Zotero bibliography import and restart. The fixtures and authored code are agent validation examples, not your learning achievements. PDF annotation selection is checked separately and is not certified by the bibliography-only self-service fixture. Human learning effectiveness and your personal usability trial remain unproven.
