# Code and knowledge, without a vault ceiling

Research covered URI navigation, Canvas/JSON Canvas, Bases/property queries,
MathJax, Markdown embeds, backlinks, templates, daily notes, Excalidraw,
LaTeX Suite, current obsidian.nvim completion and the newer Obsidian CLI.

- [Obsidian URI](https://obsidian.md/help/uri): open exact files; keep code-return links local.
- [Canvas](https://obsidian.md/help/Plugins/Canvas): native file nodes, text nodes and meaningful edges.
- [Bases syntax](https://obsidian.md/help/bases/syntax): query note properties without duplicating data.
- [Math and extended syntax](https://obsidian.md/help/advanced-syntax): equations remain Markdown.
- [obsidian.nvim](https://github.com/obsidian-nvim/obsidian.nvim): vault links, search, backlinks and completion inside the editor.
- [Excalidraw integration](https://github.com/zsviczian/obsidian-excalidraw-plugin): pen diagrams live beside project notes.

The boundary is a file format, not an application. No forced folder migration,
no background scan of every vault, no automatic agent submission, and no fixed
list of three vaults. Choose tools per task: code in Neovim, visual thinking in
Obsidian, normal Markdown in either. New containers share configuration but keep
native tools isolated by ABI and environment.
