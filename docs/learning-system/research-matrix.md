# Research decisions

The supplied planning investigation remains the design input. Its reported search
inventory is not reproduced or presented as implementation validation. Existing
research.md and practice-design.md retain the original inspected-source notes.

| Evidence | Source | Decision | Limit |
|---|---|---|---|
| A | Dunlosky et al. 2013; Freeman et al. 2014 | Reconstruction, delayed checks, work beyond consumption | No universal curriculum or competence score |
| A | National Academies 2018 | Contextual transfer, learner goals and autonomy | Context matters; retrieval is not all expertise |
| A | Renkl 2014; Sinha/Kapur 2021; Shute 2008 | Optional guidance, preserved failure, learner-controlled feedback | No mandatory struggle timer |
| A | Schroeder/Kucera 2022 | Preserve misconception and correction history | No automatic belief correction |
| C | Hotz; Karpathy; LLVM; Carmack; Colin Galen | Build spine, baselines, explicit state, five practice modes | Adaptations of public work, not private habits |
| B | [Quickshell Process](https://quickshell.org/docs/v0.3.0/types/Quickshell.Io/Process/) | NDJSON worker with enabled stdin and lifecycle ownership | Accessed 2026-10-08; native acceptance still required |
| B | [Restic restore](https://restic.readthedocs.io/en/stable/050_restore.html) | Restore snapshot into a new location and verify | Accessed 2026-10-08; local recovery is not off-device protection |
| D | Zotero/Obsidian/researcher discussions in the approved plan | Versioned import ownership, instant capture, resume purpose | Individual reports, not consensus |
| E | Noesis architecture | Markdown authority and disposable SQLite | Validate actual UI and synchronization behavior |
