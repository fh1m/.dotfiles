# Start here

Open this folder as an Obsidian vault. Enable its native command line interface
in Settings → General → Advanced. Use `oasis use PATH` to select this subject.

Open Home, choose one capability, then write the smallest interesting question
and a test in Current Frontier. Do not complete a grand prerequisite curriculum
before building. Gate, parallel and deep-descent are different jobs.

Core Templates, Daily Notes, Canvas, Backlinks, Properties and Bases are enabled.
No community plugin is required. Math uses `$inline$` or `$$display$$`.

`oasis new concept "Name"`, `oasis new lab "Test"`, `oasis today`, `oasis due`,
`oasis doctor`. Use the Oasis Subjects panel to move freely between vaults.

Your notes stay local; no remote is configured. See AGENTS.md for the teaching
protocol, and the dotfiles learning-system guide for backups and keyboard actions.
